## Permisos de Vanilla

Esta es una lista de todos los permisos adicionales de Vanilla.

| Nodo de permiso                   | Descripción                                                                                                           | ¿Los jugadores tienen permiso de forma predeterminada? |
|-----------------------------------|-----------------------------------------------------------------------------------------------------------------------|-------------------------------------|
| minecraft                         | Permite al usuario usar todas las utilidades y los comandos de Vanilla.                                               | No                                  |
| minecraft.admin.command\_feedback | Recibir difusiones de comandos cuando sendCommandFeedback sea true.                                                   | No                                  |
| minecraft.nbt.place               | Permite al usuario colocar bloques restringidos con NBT en el modo creativo.                                           | No                                  |
| minecraft.nbt.copy                | Permite al usuario copiar NBT en el modo creativo.                                                                    | Sí                                  |
| minecraft.debugstick              | Permite al usuario usar la debug stick en el modo creativo.                                                            | No                                  |
| minecraft.debugstick.always       | Permite al usuario usar la debug stick en todos los modos de juego.                                                    | No                                  |
| minecraft.commandblock            | Permite al usuario usar bloques de comandos.                                                                           | No                                  |
| minecraft.command.selector        | Permite al usuario usar [selectores de objetivo](https://minecraft.wiki/w/Target_selectors) en los argumentos de comandos. | No                                  |
