Generalmente es una buena idea admitir traducciones en su complemento, especialmente si desea atraer a la base de usuarios más grande. Adventure simplifica esto al agregar una capa de traducción del lado del servidor a casi todo el texto que termina mostrándose a los clientes.
:::note[Javadocs]
Los Javadocs de Adventure para traducciones de todo lo relacionado se pueden encontrar [aquí](jd:adventure:net.kyori.adventure.translation.package-summary).
:::
## Traductor global

Toda la traducción se realiza a través de [](jd:adventure:net.kyori.adventure.translation.GlobalTranslator). Puede renderizar las traducciones usted mismo y agregar nuevas fuentes para las traducciones.

Puede agregar fuentes a `GlobalTranslator` creando instancias de [](jd:adventure:net.kyori.adventure.translation.TranslationStore) o implementando la interfaz [](jd:adventure:net.kyori.adventure.translation.Translator) usted mismo.

## Dónde funcionan las traducciones

Vanilla Minecraft maneja las traducciones en el cliente utilizando los archivos de idioma incluidos con el cliente o proporcionados a través de paquetes de recursos. Si no desea enviar archivos de idioma personalizados en un paquete de recursos, las traducciones del lado del servidor son la única alternativa. Funcionan en cualquier lugar donde exista la API del componente, excepto [](jd:paper:org.bukkit.inventory.ItemStack) texto para mostrar como el nombre para mostrar o la historia. Por lo tanto, el chat, los nombres para mostrar de las entidades, los marcadores, las listas de pestañas, etc., todos admiten traducciones.

## Ejemplos

### `ResourceBundle`
```properties title="src/main/resources/your/plugin/Bundle_en_US.properties"
some.translation.key=Translated Message: {0}
```

```java
TranslationStore.StringBased<MessageFormat> store = TranslationStore.messageFormat(Key.key("namespace:value"));

ResourceBundle bundle = ResourceBundle.getBundle("your.plugin.Bundle", Locale.US);
store.registerAll(Locale.US, bundle, true);
GlobalTranslator.translator().addSource(store);
```
Esto crea un nuevo `TranslationStore` bajo un espacio de nombres específico. Luego, se crea un [](jd:java:java.util.ResourceBundle) a partir de un paquete ubicado en el classpath con el [](jd:java:java.util.Locale) especificado. Finalmente, ese `ResourceBundle` se agrega a la tienda. Luego, esa tienda se agrega como fuente al archivo `GlobalTranslator`. Esto hace que todas las traducciones estén disponibles en el lado del servidor.

Ahora puede utilizar sus claves de traducción en componentes traducibles.
```java
Component.translatable("some.translation.key", Component.text("The Argument"))
```
Esto se mostrará a los clientes que utilicen el idioma inglés de EE. UU.: `Translated Message: The Argument`.
