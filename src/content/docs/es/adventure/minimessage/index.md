El formato MiniMessage es una representación sencilla de los componentes del chat mediante cadenas, diseñada para que los usuarios finales puedan aprenderla fácilmente y los desarrolladores ampliarla.

```mm
Hola <rainbow>mundo</rainbow>, ¿no es divertido <blue><u><click:open_url:'https://docs.papermc.io/adventure/minimessage/'>MiniMessage</click></u></blue>?
```

Si quieres escribir mensajes con MiniMessage, consulta el [formato MiniMessage](/es/adventure/minimessage/format); si quieres desarrollar software que use MiniMessage, consulta la [descripción general de la API](/es/adventure/minimessage/api).
