## Se detectó una versión de Java no compatible. ¿Qué debo hacer? {#unsupported-java-detected-what-do-i-do}

Las versiones de Java no compatibles, de acceso anticipado o internas suelen carecer de funciones, tener problemas conocidos o estar directamente rotas.
Por ello, no podemos ofrecer asistencia para servidores que utilicen esas versiones.
Deberías instalar una versión compatible de Java, tal como se explica [aquí](/es/misc/java-install).

Si aun así quieres continuar, sabiendo que lo haces bajo tu propia responsabilidad y que NO recibirás asistencia, puedes desactivar la comprobación mediante una propiedad del sistema, tal como se explica [aquí](/es/paper/reference/system-properties#paperignorejavaversion).
