La página [Argumentos y literales](/es/paper/dev/command-api/basics/arguments-and-literals) cubre los argumentos nativos de Brigadier más utilizados. Pero Minecraft define algunos más en los que se envuelve Paper. Se puede acceder a ellos en un contexto estático utilizando la clase [](jd:paper:io.papermc.paper.command.brigadier.argument.ArgumentTypes). Repasaremos todos ellos en esta sección.
