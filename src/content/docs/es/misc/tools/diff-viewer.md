Visor enriquecido de diferencias entre varios archivos, compatible con confirmaciones, solicitudes de cambios y comparaciones de GitHub, así como
con archivos diff y patch.
El visor de diferencias de GitHub es excelente para la mayoría de los casos, pero tiene varias limitaciones,
especialmente al trabajar con diferencias grandes, en las que puede funcionar mal o incluso bloquearse.
El visor de diffs.dev busca resolver este problema y ofrecer funciones adicionales
útiles para PaperMC y en general, como el tratamiento especial de diferencias de segundo orden. También
hemos creado una extensión para Firefox y Chrome que facilita abrir diferencias de GitHub en el
visor.

- https://diffs.dev - El visor de diferencias
- [Chrome Extension](https://chromewebstore.google.com/detail/patch-roulette/feaaoepdocmiibjilhoahgldkaajfnhb)
- [Firefox Add-on](https://addons.mozilla.org/en-US/firefox/addon/patch-roulette/)
- https://github.com/PaperMC/diff-viewer - Repositorio de GitHub
