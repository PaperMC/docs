---

Las plataformas nativas integran Adventure directamente con la API que proporcionan y la incluyen automáticamente.
Esto les permite integrar Adventure mejor con el resto del juego y evita que los usuarios tengan que encargarse de distribuir
Adventure y algún adaptador de plataforma.

Los siguientes programas ofrecen compatibilidad nativa con Adventure.

| Plataforma | Versión mínima                       | Notas adicionales                                                                                                 |
|------------|--------------------------------------|------------------------------------------------------------------------------------------------------------------|
| Sponge    | Sponge 8 (1.16.5)                    |                                                                                                                  |
| Velocity  | 1.1.0 build 158                      | Para obtener más información, consulta la [documentación de Velocity](/es/velocity/dev/pitfalls#audience-operations-are-not-fully-supported) |
| Paper     | 1.16.5 build 473                     |                                                                                                                  |
| Minestom  | Build 7494725                        | Para obtener más información, consulta [Minestom Wiki](https://minestom.net/docs/feature/adventure)              |
| Fabric    | `adventure-platform-fabric` 5.3.0    | No es totalmente nativo, pero las interfaces inyectadas ofrecen una experiencia casi nativa                      |
| Fidorial  | 0.1.0                                | Para obtener más información, consulta el [repositorio de Fidorial en GitHub](https://github.com/Fidorial/Fidorial) |
