PaperMC ofrece un servicio de descargas para facilitar el acceso automatizado a las descargas. Puedes encontrar la documentación completa en
[la documentación del servicio de descargas](https://fill.papermc.io/swagger-ui/index.html#/).

:::danger

**No recomendamos en absoluto** usar compilaciones inestables ni actualizadores automáticos en entornos de producción.

:::

Todas las solicitudes deben incluir ahora un encabezado User-Agent válido que:
- Identifique claramente tu software o empresa
- No sea genérico (por ejemplo, curl, wget o valores predeterminados similares)
- Incluya una URL o dirección de correo electrónico de contacto (por ejemplo, una página de inicio, información del bot o un correo de soporte)

**Algunos ejemplos:**
```
mc-image-helper/1.39.11 (https://github.com/itzg/docker-minecraft-server)
nodecraft/packifier/1.0.0 (staff@nodecraft.com)
```

## Ejemplos de la API REST

:::note

Para los siguientes ejemplos, es necesario tener instalado `jq`. Puedes instalarlo con `sudo apt-get install jq` en Debian/Ubuntu.

:::

### Obtener la última versión

```shell
#!/usr/bin/env sh

PROJECT="paper"
USER_AGENT="cool-project/1.0.0 (contact@me.com)"

LATEST_VERSION=$(curl -s -H "User-Agent: $USER_AGENT" https://fill.papermc.io/v3/projects/${PROJECT} | \
    jq -r '.versions | to_entries[0] | .value[0]')

echo "La última versión es $LATEST_VERSION"
```

Esto obtiene la última versión disponible de Minecraft para el proyecto indicado.

### Obtener el número de la última compilación estable

```shell replace
#!/usr/bin/env sh

PROJECT="paper"
MINECRAFT_VERSION="\{LATEST_PAPER_RELEASE}"
USER_AGENT="cool-project/1.0.0 (contact@me.com)"

LATEST_BUILD=$(curl -s -H "User-Agent: $USER_AGENT" https://fill.papermc.io/v3/projects/${PROJECT}/versions/${MINECRAFT_VERSION}/builds | \
  jq -r 'map(select(.channel == "STABLE")) | .[0] | .id')

if [ "$LATEST_BUILD" != "null" ]; then
  echo "La última compilación estable es $LATEST_BUILD"
else
  echo "No se encontró ninguna compilación estable para la versión $MINECRAFT_VERSION :("
fi
```

Esto obtiene la última compilación estable disponible para el proyecto y la versión de Minecraft indicados.

### Descargar la última compilación estable

```shell replace
#!/usr/bin/env sh

PROJECT="paper"
MINECRAFT_VERSION="\{LATEST_PAPER_RELEASE}"
USER_AGENT="cool-project/1.0.0 (contact@me.com)"

# Primero comprueba si la versión solicitada tiene una compilación estable
BUILDS_RESPONSE=$(curl -s -H "User-Agent: $USER_AGENT" https://fill.papermc.io/v3/projects/${PROJECT}/versions/${MINECRAFT_VERSION}/builds)

# Comprueba si la API devolvió un error
if echo "$BUILDS_RESPONSE" | jq -e '.ok == false' > /dev/null 2>&1; then
  ERROR_MSG=$(echo "$BUILDS_RESPONSE" | jq -r '.message // "Unknown error"')
  echo "Error: $ERROR_MSG"
  exit 1
fi

# Intenta obtener la URL de una compilación estable para la versión solicitada
PAPERMC_URL=$(echo "$BUILDS_RESPONSE" | jq -r 'first(.[] | select(.channel == "STABLE") | .downloads."server:default".url) // "null"')
FOUND_VERSION="$MINECRAFT_VERSION"

# Si no hay una compilación estable para la versión solicitada, busca la última versión con una compilación estable
if [ "$PAPERMC_URL" == "null" ]; then
  echo "No hay compilación estable para la versión $MINECRAFT_VERSION; se busca la última versión con compilación estable..."

  # Obtén todas las versiones del proyecto (usando la misma estructura del endpoint que el ejemplo "Obtener la última versión")
  # Las versiones están organizadas por grupos; por eso necesitamos extraer todas las versiones de todos los grupos
  # Luego las ordenamos correctamente como versiones semánticas (las más nuevas primero)
  VERSIONS=$(curl -s -H "User-Agent: $USER_AGENT" https://fill.papermc.io/v3/projects/${PROJECT} | \
    jq -r '.versions | to_entries[] | .value[]' | \
    sort -V -r)

  # Recorre las versiones para encontrar una con una compilación estable
  for VERSION in $VERSIONS; do
    VERSION_BUILDS=$(curl -s -H "User-Agent: $USER_AGENT" https://fill.papermc.io/v3/projects/${PROJECT}/versions/${VERSION}/builds)

    # Comprueba si esta versión tiene una compilación estable
    STABLE_URL=$(echo "$VERSION_BUILDS" | jq -r 'first(.[] | select(.channel == "STABLE") | .downloads."server:default".url) // "null"')

    if [ "$STABLE_URL" != "null" ]; then
      PAPERMC_URL="$STABLE_URL"
      FOUND_VERSION="$VERSION"
      echo "Se encontró una compilación estable para la versión $VERSION"
      break
    fi
  done
fi

if [ "$PAPERMC_URL" != "null" ]; then
  # Descarga la última versión de Paper
  curl -o server.jar $PAPERMC_URL
  echo "Descarga completada (versión: $FOUND_VERSION)"
else
  echo "No hay compilaciones estables disponibles para ninguna versión :("
  exit 1
fi
```

Este es el uso más habitual de la API. Descargará la última compilación estable del proyecto y la
versión de Minecraft indicados. Siempre debes publicar y usar compilaciones estables. Las compilaciones experimentales pueden contener errores y
no reciben soporte.

## Ejemplos de la API GraphQL

Fill también admite una API GraphQL, disponible en `https://fill.papermc.io/graphql`.
La API GraphQL de Fill usa paginación estándar; puedes obtener más información [aquí](https://graphql.org/learn/pagination/).

Hay un entorno de pruebas GraphQL integrado en https://fill.papermc.io/graphiql?path=/graphql.
Herramientas habituales para API, como Postman, inspeccionan la API y ofrecen una interfaz para crear consultas.

### Obtener la última versión
```graphql
query LatestVersion {
    project(key: "paper") {
        key
        versions(first: 1, orderBy: {direction: DESC}) {
            edges {
                node {
                    key
                }
            }
        }
    }
}
```

### Obtener el número de la última compilación estable
```graphql
query LatestStableBuild {
    project(key: "paper") {
        key
        versions(first: 1, orderBy: {direction: DESC}) {
            edges {
                node {
                    key
                    builds(filterBy: { channel: STABLE }, first: 1, orderBy: { direction: DESC }) {
                        edges {
                            node {
                                number
                            }
                        }
                    }
                }
            }
        }
    }
}
```

### Obtener la URL de descarga de la última compilación estable
```graphql
query LatestStableBuildDownloadURL {
    project(key: "paper") {
        key
        versions(first: 1, orderBy: {direction: DESC}) {
            edges {
                node {
                    key
                    builds(filterBy: { channel: STABLE }, first: 1, orderBy: { direction: DESC }) {
                        edges {
                            node {
                                number
                                download(key: "server:default") {
                                    name
                                    url
                                    checksums {
                                        sha256
                                    }
                                    size
                                }
                            }
                        }
                    }
                }
            }
        }
    }
}
```
