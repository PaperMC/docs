Adventure es compatible con la versión más reciente de BungeeCord y con derivados compatibles
con BungeeCord, como Waterfall.

:::danger

La implementación de la plataforma Adventure para BungeeCord y el serializador de componentes de BungeeCord ya no se mantienen.
El equipo de Adventure ya no ofrece asistencia para estas bibliotecas.

Recomendamos que quienes usan estas bibliotecas migren a programas modernos con [compatibilidad nativa con Adventure](/es/adventure/platform/native) (por ejemplo, [Velocity](/es/velocity)).

:::

## Uso

Primero debes obtener un objeto `BungeeAudiences` mediante `BungeeAudiences.create(plugin)`. Este objeto es seguro para subprocesos
y, si es necesario, se puede reutilizar desde distintos subprocesos. También debes *cerrar* este objeto al desactivar el plugin.

Ten en cuenta que no todas las funciones están disponibles en el proxy. Se admiten los mensajes de chat, los mensajes de la barra de acción, los títulos, las barras de jefe
y los encabezados y pies de la lista de jugadores; las demás solicitudes fallarán silenciosamente.

A continuación se muestra un ejemplo sencillo de inicialización correcta de esta plataforma:

```java title="MyPlugin.java"
public class MyPlugin extends Plugin {

    private BungeeAudiences adventure;

    public BungeeAudiences adventure() {
        if (this.adventure == null) {
            throw new IllegalStateException("Cannot retrieve audience provider while plugin is not enabled");
        }
        return this.adventure;
    }

    @Override
    public void onEnable() {
        this.adventure = BungeeAudiences.create(this);
    }

    @Override
    public void onDisable() {
        if (this.adventure != null) {
            this.adventure.close();
            this.adventure = null;
        }
    }
}
```

## Serializadores de componentes

Para las funciones que `Audience` no admite, `BungeeComponentSerializer` permite convertir entre
los [componentes](/es/adventure/text) de Adventure y la API nativa de componentes de chat de BungeeCord, y viceversa.

:::cautions

En algunas áreas del proxy (en particular, al enviar respuestas de la lista de servidores), no se puede inyectar correctamente el serializador de componentes
a menos que se haya inicializado una instancia de `BungeeAudiences`. El uso de instancias de `Component` de Adventure **no**
funcionará sin una instancia de `BungeeAudiences`.

:::
